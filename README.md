# Reverse Keyboard

Type in binary. Eight toggle switches set an ASCII character, and a small OLED shows it alongside up to three stored characters. Press the red button and the board types them on the computer as a real USB keyboard.

Board: Reverse Keyboard REV1.0, designed by [Just Different Creations](https://justdif.com) in Lufkin, Texas. See it on the [PCB Projects](https://justdif.com/pcb-projects/) page.

## How it works

- The board plugs into a computer over USB and shows up as a HID keyboard named "ASCII Keyboard".
- **8 bit switches** (PORTD) set the current character in binary. The OLED shows the bits and the character (control codes show by name, like `ESC` or `CR`).
- **3 storage slots**, each with a Store and a Clear button, save the current character to rows 1 to 3 on the screen.
- **3 slot toggles** choose which stored characters are included when you send.
- The **red Send button** types the active stored characters and then the current character, so up to four keys go out in one press (for example a modifier followed by a letter).

## Hardware

- MCU: AVR64DU28 (built-in USB)
- Display: 128x64 SSD1309 OLED over I2C (TWI0, address 0x3C, 400 kHz)
- Pin setup, clock, interrupts and the USB HID stack are generated with MPLAB Code Configurator (MCC Melody)

## Building and flashing

- MPLAB X IDE with the XC8 compiler (built with v3.10)
- Programmer: PICkit 5
- The `mcc_generated_files` folder is not in this repo. Open the project in MPLAB X, open MCC (it loads `AVR16DU28_Reverse_Keyboard.mc3`), and click **Generate** to recreate it. Then build and program the board.

## Files

| File | What it does |
| --- | --- |
| `main.c` | Sets up the system, interrupt handlers, USB and the display, then services USB |
| `input.c/.h` | Switch and button handlers, storage slots, and sending keys |
| `ascii_map.c/.h` | ASCII to HID keycode conversion and control-code names |
| `ssd1309.c/.h` | OLED driver with a double-size text mode |
| `i2c.c/.h` | Minimal TWI0 I2C master |
| `font5x7.c/.h` | 5x7 font table |
